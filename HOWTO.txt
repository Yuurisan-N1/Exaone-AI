Exaone Bot HOWTO

Short version, six steps.

1. INSTALL RUST
   Windows / Linux / macOS: https://rustup.rs  then reopen the terminal and check:
       rustc --version

2. POINT AT A PROXY
   Open proxy.txt and put one proxy per line, for example:
       http://user:pass@host:port
   The identity host is region locked, so a direct run answers "Access Restricted" and the
   bot says so in one line before it touches the mailbox. One line is one exit address; the
   cycle takes them in order.

3. BUILD
       cargo build --release
   or let the wrapper do it:
       ./run.sh build

4. CREATE ONE ACCOUNT
       ./run.sh enroll 1
   The bot opens a mailbox, starts the signup, waits for the six digit code, clears the
   consent gate, walks the portal oauth hop, mints an API key and then runs one chat to
   prove the key works. The key is appended to data.txt, one key per line. The mailbox, the
   password, the device and the key are kept in session.json.
   One run, one account. Run it again only when you want another one.

5. LOOK BEFORE YOU CLAIM
       ./run.sh probe
   This reads the hosts, the model endpoint and the egress country of every proxy line.

6. RUN
       ./run.sh run        foreground, one cycle
       ./run.sh bg         background, log in exaone-bot.log
       ./run.sh screen     detached screen session
       ./run.sh stop       stop the background run

config.json holds sleep_seconds, the pause between cycles. data.txt is an output; it only
ever holds keys.
